# Day 5 – Java & Spring Boot Fundamentals

## Goal

Learn the basic Java and Spring Boot concepts used in the banking application.

## What I Learned

### 1. Class

A class is a blueprint that defines data and behavior.

Examples from the project:

- Auth
- Account
- Transaction
- Notification

### 2. Object

An object is an instance of a class.

A class defines what an object contains, while an object represents an actual instance.

### 3. Variable

A variable stores data.

Examples:

- username
- password
- email
- account balance

### 4. Method

A method performs an action.

Examples:

- login()
- register()
- getAllUsers()
- updateAuth()
- deleteAuth()
